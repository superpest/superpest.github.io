# 书虫 · 爱情与金钱 — 精读与听力

把超星专题页《书虫1级〈爱情与金钱〉双语+MP3》重新设计成的一个本地学习站：
中英逐段对照、点词即查、生词本与复习、原声播放器、系统朗读、进度续读、三套主题、离线可用。

原页面：<https://zhuanti.chaoxing.com/mobile/mooc/tocourse/89691708>

---

## 怎么打开

浏览器不允许 `file://` 页面读取本地数据，所以用一个静态服务器打开：

```bash
cd love-money-study
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

第一次打开后，Service Worker 会缓存应用外壳与课程数据，之后断网也能继续读。

## 功能

**阅读**
- 中英逐段对照；可切换「双语 / 仅英文 / 仅中文」
- 字号 16–26px、三档行距
- 纸白 / 米黄 / 暗夜三套主题，顶栏一键轮换
- 点按任意英文单词：联网查音标与释义（自动补中文），选中即朗读（设置里可关），可直接收入生词本

**听力**
- 直接读取本机 `audio/ch1.mp3` … `ch7.mp3`，离线播放（不需要上传）
- 播放器：上一章 / 下一章、±10 秒、0.75–1.75 倍速、A-B 复读、定时暂停、进度拖拽
- 没有音频时，可用系统语音（Web Speech API）逐段朗读，自动高亮并跟随滚动
  播放器会显示「朗读中 · 第 n / 总段数」和段落进度条；未导入音频时进度条上直接提示「导入音频」
- 章节结束自动进入下一章（可关）

**生词与进度**
- 生词本：搜索、发音、标记「已掌握」、删除、导出 CSV
- 复习模式：翻卡 + 「还不熟 / 记住了」，不熟的词会回到队列末尾
- 阅读进度按章节记录，回到页面自动停在读到的位置
- 累计学习时长统计

**其它**
- 键盘：`空格` 播放/暂停、`← →` 切换章节、`J / K` 上下段、`D` 换主题、`Esc` 关闭浮层
- 移动端：目录抽屉、底部播放器
- PWA：可「添加到主屏幕」

## 音频

7 章原声已经下载到 `audio/ch1.mp3` … `audio/ch7.mp3`，打开页面直接可播，时长与课程元信息一致
（6:37 / 11:10 / 11:32 / 12:16 / 10:21 / 8:08 / 14:06）。「简介」章节本身没有音频，可用朗读按钮收听中文。

这些地址来自课程页自身的音频模块：页面只给出 `objectid`，播放地址由站内接口
`https://zhuanti.chaoxing.com/special/files/{objectid}/fileDetail?key=httphd` 返回，
再下载为本地文件（脚本见 `../tools/fetch_audio.py`）。文件名按 `ch{index}.mp3` 约定，页面启动时自动识别。

如果以后换了章节或想换音源，直接替换 `audio/` 里的文件即可：
命名为 `ch1.mp3` … `ch7.mp3`（对应 Chapter 1–7），页面启动时自动识别；
在设置（右上齿轮）→ 音频 里可以随时「重新检测本地音频」，查看每一章是否就绪。
页面不会接收上传，也不使用浏览器缓存里的音频，只读取这个目录下的文件。

Service Worker 会把这些音频一并缓存，之后断网也能听。

## 目录结构

```
love-money-study/
├── index.html              页面
├── assets/
│   ├── style.css           设计系统与全部样式
│   ├── app.js              路由、阅读器、查词、生词本、播放器
│   └── icon.svg
├── data/
│   ├── course.json         结构化课程数据（8 章 / 段落 / 音频元信息）
│   └── course.js           同上，包成全局变量，便于 file:// 直接打开
├── audio/                  可选：放 ch1.mp3 … ch7.mp3
├── manifest.webmanifest
└── sw.js                   离线缓存
```

`data/course.json` 由 `../tools/build_content.py` 从保存下来的章节页解析生成，
英文正文中的全角标点已规范化为英文标点。要改标题、拆分段落或补充注释，直接改这个文件即可，
再重新生成 `course.js`（或让页面改为 `fetch('data/course.json')`）。
